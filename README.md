# need-blood
Emergency blood donor matchmaking platform
# problem-Statement
Create a localized directory of voluntary blood donors on campusDuring emergencies,users can broadcast a request for a specific blood type, which alerts registered donors via SMS
# Solution
need-blood is a smart blood donor matchmaking platform thatconnects patients with nearby voluntary donors and sends emergency alerts through SMS notifications.
# Features
- Donor registration
- Blood group matching
- Emergency blood request system
- SMS alerts todonors
- Availabilty status tracing
- Search nearby donors
